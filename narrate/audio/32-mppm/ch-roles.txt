The fix is to give each instance its own storage. Install the dedicated server package, and netcode's assembly definition defines a symbol for multiplayer roles. That symbol switches the preference getter to ask the roles manager first, and only fall back to the shared key if roles are disabled. Each player now carries its own role, saved in the play mode system data file next to its name and its identifier. Set the main editor to client and server, set the second player to client, and the topology is finally what you drew.
