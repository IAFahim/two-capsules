Now the second shared thing, and it is the one that crashes. The play mode type, which decides whether an instance builds a server world, a client world or both, is stored in editor preferences under a key scoped by the product name. Not by the instance. Not by the player index. By the product name. Every process reading that key gets the same answer, and its default is client and server. So the second editor happily concludes it should build a server world too.
