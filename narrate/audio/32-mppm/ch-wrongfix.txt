The instinct is to open the play mode tools window in the second instance and set it to client. You cannot. An additional editor does not get that window. And the value you would be changing in the main editor is the shared one, which would change it for the host too. So you are being asked to configure two independent boards by editing one shared memory chip, and there is no version of that which works. The problem is not the setting. The problem is that there is only one of it.
