Look at what is actually on disk. Inside the library folder there is a virtual project directory per player, and inside each one, the assets folder and the project settings folder are symbolic links pointing straight back at your real project. There is no copy, no sync step and no divergence, because there is only ever one file. What the virtual project does keep for itself is small: a private library holding window layout, build profiles and a shader cache. The compiled assemblies are not in there. So an edit appears instantly in every instance, and a reimport stalls all of them at once, for exactly the same reason.
