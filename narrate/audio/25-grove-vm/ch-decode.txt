A blob cannot hold a function pointer, because a function pointer is an address and the whole point of the image is that it contains no addresses. So the instruction can only store a number, and the decoding has to live in real compiled code. That is what the generator emits: a switch on that integer, with one case per claimed opcode. It emits a separate copy for each context type, so everything is specialised and nothing is generic at runtime. Burst turns a dense integer switch into a jump table and will happily inline straight through it. No virtual call anywhere.
