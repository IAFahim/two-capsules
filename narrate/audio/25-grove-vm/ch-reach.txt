The methods are static and hold no fields, which sounds crippling until you see the context. Every node receives a context struct by reference, and the fields on it are yours: the buffers for this chunk, the component lookups, a command buffer to write into. A partial declaration and the generator fills in the plumbing by reading your field types. So a node is a pure function of its own data and that context, and the context is the only window it has onto the world. Register file on one side, memory mapped input and output on the other.
