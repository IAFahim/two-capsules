Here is the part I find genuinely delightful. The authoring object exposes a node type number, and that number gets written into the header when the image is built. Separately, an attribute on a static method claims the same number for that method. Two entirely different assemblies agreeing on an integer. That is exactly what an instruction set architecture is, and each package takes its own range, counting downward from a negative offset, so that grove, canopy and nerve can extend the same machine without ever colliding.
