A blob pointer does not store an address. It stores a signed thirty two bit offset, and dereferencing it takes the address of the offset field itself and adds the offset to that. Read that twice, because everything else follows from it. The pointer is relative to its own location, so nothing inside the block knows or cares where the block lives. You can memory copy it, write it to disk, read it back at a different address, map it into a different process, and every internal reference is still correct. It is position independent code, applied to data.
