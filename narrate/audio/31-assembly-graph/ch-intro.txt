This map is the smallest one in the book and it describes the failure that cost the most hours. Unity compiles one library per assembly definition file, and that file is a linker script with a gate in it. The gate is an AND across every symbol in a list. All inputs high, the assembly compiles. One input low, the assembly does not compile. Not partially. At all. And the gate has no output pin you can probe, because nothing is logged when it evaluates false.
