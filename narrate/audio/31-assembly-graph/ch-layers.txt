Components, systems and contexts go in the runtime assembly, which builds for all platforms and takes only the package constraints. Settings assets and bakers that touch authoring types go in the authoring assembly, which adds the editor symbol on top. Menu items and graph construction go in the editor assembly, which is restricted to the editor platform outright. References point upward only: editor may reference authoring, authoring may reference runtime, and nothing runtime is ever allowed to reach down. That is the whole contract, and it turns a build day surprise into a compile error.
