A source generator has already written a system for each of your command types. It queries for entities holding that type plus a send request, writes an index, a bit length and your serialised payload into a byte buffer hanging off the connection entity, and destroys the request entity. Nothing has been sent yet. The buffer is drained at the end of the frame. This matters because the order things are sent in is the order they were serialised, which is not necessarily the order in which you created the entities.
