The name is a lie, and getting past it is most of the work. Nothing here calls anything. You create an entity. That entity carries your data component and a marker saying it wants to be sent. A generated system finds it, serialises it, and destroys it. On the other machine an entity appears carrying your data component and a marker saying where it came from. Two entities, one on each side, that never meet. If you try to think of this as a function invocation you will keep looking for a return value that does not exist.
