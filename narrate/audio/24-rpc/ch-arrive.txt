On the receiving side, the system reads an index, looks up a function pointer, and invokes it. The default generated implementation creates an entity carrying your component and a receive request naming the connection it came from. That connection is your only sender identity, and it is the right one, because it cannot be forged by the payload. Then it checks that the number of bits read matches the number declared. If they disagree the connection is disconnected on the spot, because a desynchronised bit stream cannot be recovered from.
