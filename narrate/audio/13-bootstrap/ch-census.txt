Once someone owns creation, populating a world is one question asked repeatedly: give me every system carrying this filter flag. The server world asks for server simulation. The client world asks for client simulation plus presentation. The service world asks for a bit BovineLabs invented at position twenty one. Same question, different arguments, different worlds. There is no registry, no manifest, no ordering file. The list of systems in a world is a query result over the type system, computed at startup.
