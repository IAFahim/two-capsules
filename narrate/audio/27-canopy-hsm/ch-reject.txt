The validator refuses more than one parentless state, a composite with no default child or with two, and a cycle in the parent chain. And then the good one. State names are hashed down to a single thirty-two bit integer, and two different names can land on the same integer. So the validator brute forces the comparison at author time and refuses the graph. That is a content addressable memory with collision checking done at programming time, for the same reason you do it there: because the lookup has to be fast and correct, and a one in four billion failure found in production is not a bug you can debug.
