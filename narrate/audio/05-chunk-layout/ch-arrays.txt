After the header comes the entity array, always first, then one contiguous array per component type in this chunk's archetype. Each has a fixed stride: a transform is thirty two bytes, a ghost identity is twelve, a movement input is eight. Within an array, element three sits exactly three strides past the base. No indirection, no holes, no per element metadata. Just a run of identical records, which is the only shape a hardware prefetcher can actually predict.
