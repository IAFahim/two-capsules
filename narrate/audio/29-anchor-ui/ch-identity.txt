How does the fast side say which object it means, when it cannot hold a managed reference? By pointer. The view model keeps its unmanaged data on a small box, that box is pinned so the garbage collector cannot move it, and the resulting address is registered as a key in a dictionary that maps back to the managed object. So the identity crossing the boundary is a raw address. Pinning is not an optimisation here, it is the correctness requirement: move the object and the key stops meaning anything.
