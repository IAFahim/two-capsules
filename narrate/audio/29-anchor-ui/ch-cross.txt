When the values genuinely differ, the write has to reach managed code, and that is a real problem: compiled fast code cannot call a normal delegate. The solution is a function pointer trampoline, installed once at code load, that packs any argument struct into a pointer and a length. So one callback signature serves every kind of notification. On the other side the arguments are unpacked, the change is applied, and the ordinary property changed events are raised synchronously, right there at the write.
