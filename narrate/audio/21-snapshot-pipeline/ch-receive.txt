On the client the packet is decoded against the same baselines, and the result is written into a ring buffer attached to each ghost. Thirty two slots by default, each stamped with its tick, sized for about half a second of round trip. Note what did not happen: nothing was applied to any entity yet. The receive path only fills slots. The decision about which slot to read is somebody else's job, one system later, and it depends on which timeline that particular ghost lives on.
