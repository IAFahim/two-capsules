The buffer is declared as an untyped hash map, and that word is doing real work. Inside one buffer there is a header, a bucket array, a key array, a per entry size array, and a data region. Values are bump allocated into that data region and the size of each one is stored beside it as a small integer. So a boolean can sit next to a connection snapshot next to a node identifier, in the same map, and everything is still one allocation. It is a tiny arena allocator living inside a component.
