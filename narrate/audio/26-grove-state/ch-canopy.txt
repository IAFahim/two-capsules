This is the part that surprised me. The hierarchical state machine on top of grove does not get its own storage. It keeps its active leaf, its per parent history, and its transition version in the same map, under keys taken from the very top of the number space and counting down. Which means the executor's entire query is: entities that have this buffer. There is no state machine component to look for. The machine is a handful of entries in the memory of the machine it runs on.
