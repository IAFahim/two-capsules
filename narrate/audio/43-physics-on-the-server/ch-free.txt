The physics world is built from two queries. Dynamic bodies are entities that have a velocity. Static bodies are entities that have a collider and no velocity. The export system writes back exactly two component types, a transform and a velocity, so a static body never has anything written to it and never changes. And the validation system that complains about non ghost dynamic bodies only matches entities that have a velocity, so a static collider never trips it. The rule that falls out is where the bandwidth is won in a physics game: a body baked into a subscene that never moves needs no ghost, no snapshot and no prediction. Both worlds baked it from the same data, so both already agree.
