Everybody teaches this as three clocks. Interpolated behind, server in the middle, predicted ahead. That is the picture in most articles and it is the picture in this handbook's earlier chapters. The package disagrees, in a comment, in one line, and it is worth reading literally. It says the four timelines are, in order: interpolation tick, oldest. Then snapshot arrival tick, from the server. Then server tick, which is client prediction. Then input target tick, which is inputs being raised and sent. Four. So where did the fourth one go?
