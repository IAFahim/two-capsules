Start with the one that gets left out of every diagram, including this book's. The snapshot arrival tick. The newest server state the client actually has in hand. It is not the server's present, because that state left the server half a round trip ago. It is not the predicted tick, because the client has run ahead of it. And it is not the interpolation tick, because the client is deliberately reading behind it. It is a fourth number, it moves in jumps as packets land, and both of the client's smooth clocks are built out of it.
