Now the interesting one. The host test is defined as: is a client, and is a server. Both, on the same world. Read that again with the flag word in mind. It is asking whether one world carries both bits at once. In this project it never does. The bootstrap built two worlds, and each got exactly one bit. So the host test returns false on the server world, and false on the client world, and there is nowhere in this topology where it could return true. Our own client state system says so in a comment, right where it fills the field in.
