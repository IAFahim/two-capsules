There is no world class hierarchy here. A world carries a flags field, and netcode reads bits out of it. One bit means game server. Another means game client. A third means thin client. Every question the package asks about a world is a bit test on that word. Is this the server? Test one bit. Is this a client? Test one bit, or the thin bit. That is the entire type system, and it is the reason a world can be interrogated from Burst compiled code with no branches worth mentioning.
