Our project puts a world attribute on a settings class naming the client world. The editor reads that attribute and writes the asset onto the settings prefab registered for the client. That prefab lives in the client scene. The client scene is in a set whose mask includes client. So the baked state machine entity appears in the client world, and the system that drives it filters on client simulation. Five hops, none of them a runtime lookup, and if you ever wonder where a missing entity went, you walk that chain backwards.
