A settings asset holds a list of scene sets. Each set carries a mask naming the kinds of world it belongs to: game, service, menu, client, server, thin client. At bake time that mask is converted into world flags and stamped onto a controller entity, one per set. At runtime the loader is doing exactly one interesting thing. It takes the mask off the entity, ands it with the flags of the world it happens to be running in, and skips the entity if the result is zero. That is the whole routing system. A bitwise and.
