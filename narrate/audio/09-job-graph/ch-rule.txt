When you ask for your dependency, for every type you read it takes that type's write fence, and for every type you write it takes the write fence and every read fence. Then it combines them into one handle. Read the consequence off that: a reader waits for writers, a writer waits for writers and for all readers, and two readers of the same type are never ordered against each other. Read after write, write after read, write after write. Read after read is not a hazard, so it never becomes an edge.
