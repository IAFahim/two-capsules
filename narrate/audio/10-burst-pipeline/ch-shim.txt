If you go looking for Burst in the project's packages you will be disappointed, and it is worth knowing why. The package is version two point zero and its entire runtime folder is a single file of type forwarders. The attribute, the compiler, the intrinsics, the shared static, all of it now lives inside the editor and the engine. So there is no Burst source in the project to read. What you can read is everything that calls it, and that turns out to be more instructive anyway.
