The useful way to hold this is that Burst is a cross compiler for a restricted dialect. Same source file, same intermediate language, two different back ends. One produces managed code with a garbage collector, write barriers and safe points underneath it. The other produces machine code with none of those, because the dialect it accepts has no managed objects in it. That is why it can vectorise: it is compiling a language where aliasing is declarable and every value has a known size.
