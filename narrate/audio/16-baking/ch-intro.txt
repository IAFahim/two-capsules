Read the documentation and baking sounds like a conversion utility. It is not. It is a compiler, and once you see it that way every confusing thing about it becomes ordinary. There is a source language, which is game objects and their components. There is a front end with dependency tracking, which is bakers. There are whole program passes that run after the front end, which are baking systems. There is a dead code pass, which is the strip. And there is an object file, which is the entity section file that actually ships. The player contains no compiler at all.
