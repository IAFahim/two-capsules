So the sort key is not a hint, it is the total order. The documentation names the value to pass: the chunk index within the query. That index is stable for a given world state, which is what makes playback repeatable across runs and across machines. Pass a constant and every command ties, and the tie is not defined. Pass the entity index and you have coupled your ordering to an allocation pattern. This is the one parameter in the whole API where getting it wrong shows up as a bug you cannot reproduce.
