The first switch is a bit you own. Set it false and the system stops updating, immediately, with no other side effects. The second switch is the requirement test, and it belongs to the data. If you declared that your update requires a component, the test asks whether any chunk anywhere holds one. If you declared nothing, it returns true immediately. Think of the first as a chip select you drive by hand and the second as a data ready line the world raises for you. They are ANDed, so either one low means no update.
