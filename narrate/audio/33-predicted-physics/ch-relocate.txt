At the first world update, a configuration system walks the fixed step group, finds the physics group and every system ordered around it, and moves the whole set into the predicted fixed step group. Then it removes itself from the update list, because the move only needs to happen once. If you wrote a system that orders itself relative to physics inside the fixed step group, it is now in a different group from the thing it was ordering against, and it will silently run at the wrong time.
