The bootstrap is a single method that says: I will take over world creation. Return true from it and the engine builds nothing of its own. Netcode's implementation branches on one setting, the requested play type. Server or client and server gets a server world. Client or client and server gets a client world. Thin clients follow in the editor. Each world is then populated by asking the type manager for every system carrying a particular filter flag, which is why the two columns on this map are different things. The world flags say what the world is. The filter flags say what got put in it.
