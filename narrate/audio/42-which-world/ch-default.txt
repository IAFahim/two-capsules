This is the question that trips everyone. The default filter flag has two different expansions, and which one applies depends on who is asking. When a world is being populated, default expands to local simulation plus presentation. When a system is being classified, default expands to whatever its parent group declares as its child default, walking up the ordering chain. If that walk reaches a group with no parent, the fallback is local, server and client simulation. That fallback is the one you meet in practice, because the root simulation group carries no filter attribute at all. It is why an unfiltered gameplay system runs in every game world, including the server.
