A singleton is an entity in one world's entity manager. There is no process wide registry. Ask for one in the client world and you cannot see the copy in the server world. This is the single most common source of works in the editor, fails in the build, and the reason is mechanical. In the editor both worlds live in one process, so a system reaching for a singleton it does not own often finds a copy anyway. The wrong one, but a plausible one. Ship a dedicated server and the client world is simply not there. The lookup that was quietly wrong becomes loudly absent.
