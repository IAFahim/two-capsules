The server spawns a fireball. The server has no mesh, no material, no camera. It is tempting to conclude the server does not know where the fireball is. It does. The server computes that position every single tick, including the full rigid body trajectory, because the physics systems resolve into server simulation. What the server lacks is rendering, and rendering is a separate flag on a separate bit. The server world was populated without it, so the systems that turn a transform into pixels were never added. The transform is computed. Nobody draws it. A headless server is not a partial simulation. It is a complete simulation with the display driver unloaded.
