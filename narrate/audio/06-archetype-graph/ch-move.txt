Now the entity has to move, because its data lives in a chunk and a chunk belongs to exactly one archetype. The copy is nicer than you would guess. Both type arrays are sorted, so the copy walks them together like a merge, from the back. A type present in both gets one memory copy of count times stride. A type present only in the destination gets zeroed, and if it is one of the switchable ones its bit is set to enabled. A type present only in the source is simply dropped. So it is not one big block copy, it is one small copy per surviving component.
